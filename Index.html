UM PADRÃO QUE VOCÊ PODE VESTIR

Por que usar Decorator?

Imagine uma classe para cada visual: personagem com camisa, com botas, com camisa e botas… Ao incluir peças, a quantidade de combinações cresce rapidamente.

TRADICIONAL2⁴ = 16

classes concretas para quatro peças opcionais, incluindo a base.

DECORATOR4 + 2 = 6

classes: quatro decoradores de roupa, Personagem e RoupaDecorator.

No Decorator, cada roupa guarda uma referência ao objeto anterior. Todos oferecem visual(): a roupa chama esse método no objeto envolvido e acrescenta sua própria peça ao resultado.

personagem = new CamisaDecorator(personagem);
personagem = new ChapeuDecorator(personagem);

Para tirar uma peça, este jogo reconstrói a cadeia com as peças restantes. O tom de pele é uma configuração do personagem base.

O modo tradicional ilustra a explosão de subclasses; há outras formas de resolver um guarda-roupa sem Decorator. Aqui, as duas abordagens produzem o mesmo visual para facilitar a comparação.
